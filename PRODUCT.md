# PRODUCT.md

## Apa ini

Presentasi web 18 slide untuk tugas kelompok mata kuliah **Maritime Insight (Wawasan Kemaritiman)**, Program Studi Manajemen, Fakultas Ekonomi dan Bisnis, Universitas Halu Oleo. Topik: **Maritime Economy (Sub-CPMK-4)**. Dipublikasikan sebagai situs statis di GitHub Pages.

## Siapa penggunanya

1. **Presenter**: 8 anggota kelompok, tampil bergantian di depan kelas. Tiap orang memegang 1 subtopik = 2 slide.
2. **Penilai**: dosen pengampu. Menilai kelengkapan materi, ketepatan data, dan validitas sitasi. Kemungkinan membuka ulang link-nya sendiri setelah presentasi.
3. **Rekan sekelas**: menonton lewat proyektor kampus (kontras rendah, resolusi menengah), sebagian mengikuti dari layar HP.

## Yang menentukan berhasil atau tidak

- Semua teks terbaca dari bangku belakang lewat proyektor murah. Ini mengalahkan semua pertimbangan estetika.
- Sitasi tampil di slide, bukan disembunyikan. Sitasi adalah prasyarat mutlak penilaian tugas ini.
- Navigasi tidak pernah gagal saat presentasi live. Tidak ada state yang bisa nyangkut.
- Delapan presenter tahu persis kapan giliran mereka mulai dan berakhir.
- Bisa dibuka ulang dosen kapan saja lewat URL, tanpa perlu install apa pun.

## Batasan

- Materi sudah final dan tervalidasi (lihat `Materi_Inti_Maritime_Economy_Sub-CPMK-4.docx`). Isi tidak boleh diarang ulang atau ditambahi klaim baru.
- Angka dan sitasi sudah dicek silang ke sumber primer. Jangan diubah tanpa verifikasi ulang.
- Situs statis murni. Tidak ada backend, tidak ada build step, agar anggota kelompok non-teknis bisa ikut edit.
- Presentasi kelas, bukan produk komersial. Tidak ada CTA, tidak ada form, tidak ada analytics.

## Platform

Web (desktop-first untuk proyektor 16:9, tetap layak di HP untuk baca ulang).
